# notion_claude_api

HARLEY 实时图形演示站：光线步进（Raymarching）形态馆、GPU 粒子星系和实时流体。全部用 WebGL 着色器在浏览器里实时渲染，不需要安装任何依赖。

## 在线预览

- 首页：https://nhlfy411.github.io/notion_claude_api/
- 展示页：https://nhlfy411.github.io/notion_claude_api/showcase.html
- 粒子星系：https://nhlfy411.github.io/notion_claude_api/particles.html
- 实时流体：https://nhlfy411.github.io/notion_claude_api/fluid.html

## 页面说明

- **`index.html`（首页）**：光线步进动画作为背景，中间是 HARLEY 标题和一排可以左右滑动的卡片，下面有指示点，点一下就跳到对应卡片：
  1. 光线步进形态馆：点「立即体验 →」进入 `showcase.html`
  2. 粒子星系：点「立即体验 →」进入 `particles.html`
  3. 实时流体（小标签「03 · FLUID · BY CLAUDE」）：点「立即体验 →」进入 `fluid.html`
- **`showcase.html`（形态馆）**：完整的光线步进展示页，带形态名称和帧率显示。左上角可以返回首页。
- **`particles.html`（粒子星系）**：GPU 粒子星系，说明见文末。左上角可以返回首页。
- **`fluid.html`（实时流体）**：WebGL 实时流体（墨水 / 烟雾），说明见文末。左上角可以返回首页，右下角标着「Written by Claude」。

## 形态

首页背景用前三种形态，展示页四种都有：

1. 液态金属 · METABALLS：几个融球平滑地融合在一起
2. 极小曲面 · GYROID：陀螺极小曲面做成的镂空球壳
3. 双螺旋环 · TWISTED TORUS：扭成双螺旋的圆环
4. 分形曼德球 · MANDELBULB：8 次幂的三维分形（只在展示页）

形态每 8 秒自动切换一次，切换时会平滑过渡。

## 操作（光线步进）

- 首页：左右滑动卡片，选择要看的演示
- 拖动：旋转视角（松手后带惯性）
- 轻点：切换到下一个形态
- 右上角「配色」按钮：在幻彩、霓虹、冰蓝、熔岩之间切换（只在展示页）

## 技术要点（光线步进）

- 用全屏三角形加片元着色器做 SDF 光线步进
- 用 smooth min 融合几个形态，形态之间做插值过渡
- 加了菲涅尔反射、环境光遮蔽、发光、星空背景
- 用 ACES 色调映射，加了暗角和胶片颗粒
- 分辨率会根据帧率自动调整，手机上也能流畅运行

## 粒子星系（particles.html）

- 画面：三条旋臂的螺旋星系，内圈转得快、外圈转得慢。核心偏暖色，旋臂是蓝紫渐变，外面还有一圈闪烁的背景星
- 流畅度：手机默认 16 万粒子，电脑 32 万。帧率不够时自动减少粒子数，帧率富余时再加回来。右上角显示帧率和当前粒子数
- 操作：
  - 拖动：搅动手指附近的星河，同时旋转、倾斜整个星系（松手后带惯性）
  - 轻点：从点击位置放出一圈冲击波
  - 右上角「配色」按钮：在星河、极光、熔金之间平滑切换
- 技术要点：
  - 每个粒子只存 4 个固定参数（半径、角度、高度、随机数），位置、旋转、手指扰动和冲击波都在顶点着色器里每帧算出来
  - 粒子用叠加混合，越密越亮
  - 只用 WebGL1，不依赖浮点纹理，老手机也能跑

## 实时流体（fluid.html）

由 Claude 编写（Written by Claude）：页面右下角和首页第 3 张卡片上都有署名。

- 画面：一池会发光的彩色墨水。墨水颜色随时间沿色环变化，手指划出来是彩虹拖尾。显示时会根据墨水浓度的变化加一点立体明暗，再做色调映射，浓的地方也不会过曝
- 玩法：
  - 手指划过：沿轨迹注入速度和颜色，把流体搅出漩涡
  - 轻点：从点击位置喷出一团颜色，同时向四周喷射
  - 4 秒没人操作，会每隔 2.5 秒自动随机喷一团，画面不会变黑
- 流畅度：
  - 手机上流体网格短边 128、墨水分辨率 512，电脑上墨水分辨率 1024
  - 帧率不够时，压力迭代从 20 次往下减（最少 8 次），帧率富余再加回来；像素密度最高 1.5 倍
  - 右上角显示帧率、网格尺寸和当前迭代次数
- 技术要点：
  - 在 GPU 上解不可压缩流体方程。每帧依次算旋度、加涡度约束（让烟雾卷起小漩涡）、算散度、做压力迭代、减去压力梯度，再做平流，让速度和墨水跟着流动
  - 速度场、压力场和墨水场都存在浮点纹理里，用两张纹理来回交替读写
- 降级方案：
  - 浮点纹理按顺序试：WebGL2 半精度 → WebGL1 半精度 → WebGL1 全精度
  - 浮点纹理不支持线性插值时，在着色器里手动做双线性插值
  - 都不支持时，顶部会显示橙色提示条，改成一段跟随手指的简化墨水动画
  - 没有 WebGL 时显示「你的浏览器不支持 WebGL」；初始化出错时，错误信息会直接显示在屏幕上
