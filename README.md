# notion_claude_api

HARLEY 实时图形演示站：光线步进（Raymarching）形态馆和 GPU 粒子星系。全部用 WebGL 着色器在浏览器里实时渲染，不需要安装任何依赖。

## 在线预览

- 首页：https://nhlfy411.github.io/notion_claude_api/
- 展示页：https://nhlfy411.github.io/notion_claude_api/showcase.html
- 粒子星系：https://nhlfy411.github.io/notion_claude_api/particles.html

## 页面说明

- **`index.html`（首页）**：光线步进动画作为背景，中间是 HARLEY 标题和一排可以左右滑动的卡片，下面有指示点，点一下就跳到对应卡片：
  1. 光线步进形态馆：点「立即体验 →」进入 `showcase.html`
  2. 粒子星系：点「立即体验 →」进入 `particles.html`
  3. 更多实验：敬请期待
- **`showcase.html`（形态馆）**：完整的光线步进展示页，带形态名称和帧率显示。左上角可以返回首页。
- **`particles.html`（粒子星系）**：GPU 粒子星系，说明见文末。左上角可以返回首页。

## 形态

首页背景用前三种形态，展示页四种都有：

1. 液态金属 · METABALLS：几个融球平滑地融合在一起
2. 极小曲面 · GYROID：陀螺极小曲面做成的镂空球壳
3. 双螺旋环 · TWISTED TORUS：扭成双螺旋的圆环
4. 分形曼德球 · MANDELBULB：8 次幂的三维分形（只在展示页）

形态每 8 秒自动切换一次，切换时会平滑过渡。

## 操作（光线步进）

- 首页：左右滑动卡片，选择要看的演示
- 拖动：旋转视角（松手后带惯性）
- 轻点：切换到下一个形态
- 右上角「配色」按钮：在幻彩、霓虹、冰蓝、熔岩之间切换（只在展示页）

## 技术要点（光线步进）

- 用全屏三角形加片元着色器做 SDF 光线步进
- 用 smooth min 融合几个形态，形态之间做插值过渡
- 加了菲涅尔反射、环境光遮蔽、发光、星空背景
- 用 ACES 色调映射，加了暗角和胶片颗粒
- 分辨率会根据帧率自动调整，手机上也能流畅运行

## 粒子星系（particles.html）

- 画面：三条旋臂的螺旋星系，内圈转得快、外圈转得慢。核心偏暖色，旋臂是蓝紫渐变，外面还有一圈闪烁的背景星
- 流畅度：手机默认 16 万粒子，电脑 32 万。帧率不够时自动减少粒子数，帧率富余时再加回来。右上角显示帧率和当前粒子数
- 操作：
  - 拖动：搅动手指附近的星河，同时旋转、倾斜整个星系（松手后带惯性）
  - 轻点：从点击位置放出一圈冲击波
  - 右上角「配色」按钮：在星河、极光、熔金之间平滑切换
- 技术要点：
  - 每个粒子只存 4 个固定参数（半径、角度、高度、随机数），位置、旋转、手指扰动和冲击波都在顶点着色器里每帧算出来
  - 粒子用叠加混合，越密越亮
  - 只用 WebGL1，不依赖浮点纹理，老手机也能跑
